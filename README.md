# Visor Tactilum

Aplicación de escritorio para Windows 10/11 que conecta con una cámara de profundidad
**Luxonis OAK-D Lite**: muestra sus vistas, mide distancias y simula la respuesta de un
chaleco de 12 motores de vibración pensado para ayudar a la movilidad de personas con
discapacidad visual.

> **Prototipo en pruebas.** No es un dispositivo de seguridad y no sustituye al bastón
> blanco ni al perro guía.

## Instalar

1. Descarga `Instalar_Tactilum.exe` desde [Releases](../../releases/latest).
2. Ejecútalo. No pide permisos de administrador. Si el equipo no tiene Python, lo descarga
   e instala. La primera vez necesita internet y tarda varios minutos.
3. Abre la app con el icono **Visor Tactilum** del Escritorio.

Windows puede mostrar «Windows protegió su PC» porque el instalador no está firmado
digitalmente: elige «Más información» y luego «Ejecutar de todas formas».

## Actualizaciones

La app busca una versión nueva cada vez que se abre con internet y se actualiza sola.
Si una versión nueva no logra abrirse, vuelve a la anterior.

## Privacidad

- La app no envía datos de uso a nadie.
- Para actualizarse solo descarga archivos de este repositorio.
- La descripción con inteligencia artificial (Google Gemini) es opcional: usa tu propia
  clave y, solo cuando la pides, envía a Google la imagen de la cámara.
- Tu clave y las caminatas que grabes se guardan únicamente en tu equipo.

## Requisitos

Windows 10 u 11 de 64 bits, una cámara OAK-D Lite y, de preferencia, un puerto USB 3.
